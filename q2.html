Difference Between Writing in Google Docs and an HTML Document

These are two very different writing platforms. With Google Docs, you have a nice, refurbished UI where you don't really see the code underneath. But when you write in an HTML document, you see everything under the hood. You need to use tags to output text and styling (including CSS). Google Docs is great for writing essays, reports, assignments, and even books. Typically, either Word or Google Docs is preferred by most educational organizations. HTML, though, is typically used for more specialized purposes, like writing an article for a web page, creating a web page, or coding-related projects. This way usually takes more time, which is why schools don't ask students to open VS Code and write an essay in it. But if you think about it, Google Docs does the same thing as an HTML document. For example, when you click a button to change the boldness of your text in Google Docs, all that is happening is that a tag is being added or some CSS code.
